TITLE: Matching Multiple Regexes with RegexSet in Rust
DESCRIPTION: Shows how to use `regex::RegexSet` to efficiently match a collection of regular expressions against a single input string in one pass. The example creates a set of patterns and uses the `matches` method to get an iterator over the indices of the patterns that matched the input string 'foobar'. It also demonstrates checking if a specific pattern index matched.

SOURCE: https://github.com/rust-lang/regex/blob/master/README.md#_snippet_4

LANGUAGE: Rust
CODE:
```
use regex::RegexSet;

let set = RegexSet::new(&[
    r"\w+",
    r"\d+",
    r"\pL+",
    r"foo",
    r"bar",
    r"barfoo",
    r"foobar",
]).unwrap();

// Iterate over and collect all of the matches.
let matches: Vec<_> = set.matches("foobar").into_iter().collect();
assert_eq!(matches, vec![0, 2, 3, 4, 6]);

// You can also test whether a particular regex matched:
let matches = set.matches("foobar");
assert!(!matches.matched(5));
assert!(matches.matched(6));
```

TITLE: Matching Regex on Byte Slices in Rust
DESCRIPTION: Demonstrates how to use the `regex::bytes::Regex` API to find patterns in arbitrary byte slices (`&[u8]`) instead of UTF-8 strings (`&str`). This example finds null-terminated strings, including non-UTF-8 bytes like `\xFF`, by disabling Unicode mode with `(?-u)`. It uses `captures_iter` to extract named capture groups (`cstr`) from each match.

SOURCE: https://github.com/rust-lang/regex/blob/master/README.md#_snippet_3

LANGUAGE: Rust
CODE:
```
use regex::bytes::Regex;

let re = Regex::new(r"(?-u)(?<cstr>[^\x00]+)\x00").unwrap();
let text = b"foo\xFFbar\x00baz\x00";

// Extract all of the strings without the null terminator from each match.
// The unwrap is OK here since a match requires the `cstr` capture to match.
let cstrs: Vec<&[u8]> =
    re.captures_iter(text)
      .map(|c| c.name("cstr").unwrap().as_bytes())
      .collect();
assert_eq!(vec![&b"foo\xFFbar"[..], &b"baz"[..]], cstrs);
```

TITLE: Iterating Over Multiple Matches with regex (Rust)
DESCRIPTION: Shows how to use the `captures_iter` method from the `regex` crate to find and process all occurrences of a regex pattern within a given string. Demonstrates iterating through matches and accessing captured groups by their index.

SOURCE: https://github.com/rust-lang/regex/blob/master/regex-lite/README.md#_snippet_1

LANGUAGE: Rust
CODE:
```
use regex::Regex;

const TO_SEARCH: &'static str = "
On 2010-03-14, foo happened. On 2014-10-14, bar happened.
";

fn main() {
    let re = Regex::new(r"(\d{4})-(\d{2})-(\d{2})").unwrap();

    for caps in re.captures_iter(TO_SEARCH) {
        // Note that all of the unwraps are actually OK for this regex
        // because the only way for the regex to match is if all of the
        // capture groups match. This is not true in general though!
        println!("year: {}, month: {}, day: {}",
                 caps.get(1).unwrap().as_str(),
                 caps.get(2).unwrap().as_str(),
                 caps.get(3).unwrap().as_str());
    }
}
```

TITLE: Searching Multiple Regex Patterns with Named Captures in Rust
DESCRIPTION: This snippet demonstrates how to compile and search for multiple regular expressions simultaneously using the `regex_automata::meta::Regex` type. It shows how to define several patterns with the same named capture groups (`key`, `val`), iterate through matches in a haystack string using `captures_iter`, and extract the captured text for the named groups from each match. This requires the `regex_automata` crate.

SOURCE: https://github.com/rust-lang/regex/blob/master/regex-automata/README.md#_snippet_0

LANGUAGE: Rust
CODE:
```
use regex_automata::{meta::Regex, PatternID};

let re = Regex::new_many(&[
    r#"(?m)^(?<key>[[:word:]]+)=(?<val>[[:word:]]+)$"#,
    r#"(?m)^(?<key>[[:word:]]+)="(?<val>[^"]+)"$"#,
    r#"(?m)^(?<key>[[:word:]]+)='(?<val>[^']+)'$"#,
    r#"(?m)^(?<key>[[:word:]]+):\s*(?<val>[[:word:]]+)$"#,
]).unwrap();
let hay = r#"
best_album="Blow Your Face Out"
best_quote='"then as it was, then again it will be"'
best_year=1973
best_simpsons_episode: HOMR
"#;
let mut kvs = vec![];
for caps in re.captures_iter(hay) {
    // N.B. One could use capture indices '1' and '2' here
    // as well. Capture indices are local to each pattern.
    // (Just like names are.)
    let key = &hay[caps.get_group_by_name("key").unwrap()];
    let val = &hay[caps.get_group_by_name("val").unwrap()];
    kvs.push((key, val));
}
assert_eq!(kvs, vec![
    ("best_album", "Blow Your Face Out"),
    ("best_quote", "\"then as it was, then again it will be\""),
    ("best_year", "1973"),
    ("best_simpsons_episode", "HOMR"),
]);
```

TITLE: Iterating Over Multiple Regex Matches with regex in Rust
DESCRIPTION: Shows how to use the `captures_iter` method to find all non-overlapping matches of a regex pattern within a string. It demonstrates iterating through the matches, extracting the captured groups, and collecting them into a structured data type (a vector of tuples).

SOURCE: https://github.com/rust-lang/regex/blob/master/README.md#_snippet_1

LANGUAGE: Rust
CODE:
```
use regex::Regex;

fn main() {
    let re = Regex::new(r"(\d{4})-(\d{2})-(\d{2})").unwrap();
    let hay = "On 2010-03-14, foo happened. On 2014-10-14, bar happened.";

    let mut dates = vec![];
    for (_, [year, month, day]) in re.captures_iter(hay).map(|c| c.extract()) {
        dates.push((year, month, day));
    }
    assert_eq!(dates, vec![
      ("2010", "03", "14"),
      ("2014", "10", "14"),
    ]);
}
```
