TITLE: Reqwest GET Request Example
DESCRIPTION: Demonstrates how to make a simple GET request to a URL and retrieve the response body as text. This function creates a new internal Client on each call, so it's not recommended for making many requests. For frequent requests, create a Client instance instead.

SOURCE: https://docs.rs/reqwest/0.12.23/src/reqwest/lib

LANGUAGE: Rust
CODE:
```
/// Shortcut method to quickly make a `GET` request.
///
/// See also the methods on the [`reqwest::Response`](./struct.Response.html)
/// type.
///
/// **NOTE**: This function creates a new internal `Client` on each call, 
/// and so should not be used if making many requests. Create a
/// [`Client`](./struct.Client.html) instead.
///
/// # Examples
///
/// ```rust
/// # async fn run() -> Result<(), reqwest::Error> {
/// let body = reqwest::get("https://www.rust-lang.org").await? 
///     .text().await?;
/// # Ok(())
/// # }
/// ```
///
/// # Errors
///
/// This function fails if:
///
/// - native TLS backend cannot be initialized
/// - supplied `Url` cannot be parsed
/// - there was an error while sending request
/// - redirect limit was exhausted
pub async fn get<T: IntoUrl>(url: T) -> crate::Result<Response> {
    Client::builder().build()?.get(url).send().await
}
```

    ///
    /// # Errors
    ///

        if let Some(err) = config.error {
            return Err(err);

            proxies.push(ProxyMatcher::system());
        }

        #[cfg(feature = "http3")]

/// Proxy all HTTP traffic to the passed URL.
///
/// # Example
///
/// ```
/// # extern crate reqwest;
/// # fn run() -> Result<(), Box<dyn std::error::Error>> {
/// let client = reqwest::Client::builder()
///     .proxy(reqwest::Proxy::http("https://my.prox")?)?
///     .build()?;
/// # Ok(())
/// # }
/// # fn main() {}

    Ok(Proxy::new(Intercept::Http(proxy_scheme.into_proxy()?)))

///

///

///     .build()?;
/// # Ok(())
/// # }
/// # fn main() {}
